# 06 — Implementation Notes

Implementation notes written by developer agents (`frontend-developer`, `backend-developer`,
`data-infrastructure-developer`) while working an active task: changed files, commands run,
results, assumptions, known limitations. One file per task: `<task-id>-implementation.md`,
linked from the task file's "Implementation evidence" section.

This directory is **evidence**, not a design authority — it sits below approved contracts and
active task specs in the source-of-truth hierarchy (see `CLAUDE.md`). If an implementation note
contradicts an approved contract, that's a signal to stop and escalate, not to update the
contract from here.
